🔋 Kiểm tra Pin iPhone

Xem số lần sạc và dung lượng pin thực tế từ file phân tích của máy.

Cách lấy file nhanh:
  1. Mở Cài đặt → Quyền riêng tư & Bảo mật.
  2. Chọn Phân tích & Cải tiến → Dữ liệu phân tích.
  3. Tìm file bắt đầu bằng Analytics-YYYY-MM-DD (ưu tiên file ngày gần nhất).
  4. Bấm nút Chia sẻ → Lưu vào Tệp, rồi tải lên bên dưới.
⏳ Đang xử lý tệp...

❤️ Sức khỏe pin --

Lưu ý: Dung lượng thiết kế là thông số mà Apple in trên viên pin của iPhone.
